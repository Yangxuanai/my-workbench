# 小羊的工作台 · 手机网页版

给一名**美股夜盘交易员**（主要标的 **SOXL**）做的个人工作台。
**免备案、免上架**——放到任意静态托管，手机浏览器「添加到主屏幕」即可像 App 一样打开。

---

## 一、为什么是网页而不是小程序

你要的是「手机上固定一个入口，点开就能看」。微信小程序做不到这点便利：

| | 微信小程序 | 本方案（PWA 网页） |
| --- | --- | --- |
| 备案 | **必须**，金融资讯类目个人主体基本过不了 | 不需要 |
| 上架审核 | 需要 | 不需要 |
| 打开方式 | 微信里找小程序 | **桌面图标，一点就开** |
| 改内容 | 要重新提交审核 | 换个 json 文件，刷新即生效 |
| 服务器 | 通常要云开发 | 静态托管免费额度就够 |
| 离线 | 一般不行 | **能**（Service Worker 缓存） |

## 二、三步钉到手机桌面

### 第 1 步：传到静态托管（三选一，都免费）

**A. GitHub Pages（推荐，无需命令行）**

1. 注册 GitHub → 新建仓库，如 `my-workbench`，选 **Public**
2. 进仓库 → **Add file → Upload files** → 把 `web/` 里**所有文件**拖进去
   （`index.html` 要在仓库根目录，不要多套一层 `web/`）
3. 仓库 **Settings → Pages** → Source 选 `Deploy from a branch` → Branch 选 `main` / `root` → Save
4. 等 1 分钟，访问 `https://你的用户名.github.io/my-workbench/`

**B. Cloudflare Pages / Vercel / Netlify** — 连上仓库，构建命令留空，输出目录填 `/`。

**C. 先本地看效果** — 直接双击 `index.html`。
⚠️ 但 `file://` 下浏览器会拦截 `fetch`，**早报读不到**，这是正常的（页面会给出提示），挂到托管上就好。
想本地就能读数据：在 `web/` 下跑 `python -m http.server 8000`，访问 `http://localhost:8000`。

### 第 2 步：手机浏览器打开

- **iPhone（Safari）**：底部分享 → 「添加到主屏幕」
- **Android（Chrome）**：右上角 ⋮ → 「添加到主屏幕」/「安装应用」
- **微信内打开**：右上角「···」→「在浏览器打开」，再按上面步骤

### 第 3 步：桌面点开

桌面上多一个「羊」字图标，点开是全屏工作台，没有地址栏。

## 三、你的作息：时区结论

**上班：北京时间 周一 ~ 周五 08:00 - 16:00。休息：周六、周日。**

北京比美东快 12~13 小时，同一时刻跨美东日期，所以这五个北京工作日对应的美东区间正好是
**「周日盘后收盘 20:00 → 周五盘前开始 04:00」**。

**逐日对照**（夏令时 EDT）：

| 北京 | 上班时间 | 对应美东 |
| --- | --- | --- |
| 周一 | 08:00–16:00 | 周日 20:00 → 周一 04:00 |
| 周二 | 08:00–16:00 | 周一 20:00 → 周二 04:00 |
| 周三 | 08:00–16:00 | 周二 20:00 → 周三 04:00 |
| 周四 | 08:00–16:00 | 周三 20:00 → 周四 04:00 |
| 周五 | 08:00–16:00 | 周四 20:00 → 周五 04:00 |
| 周六 / 周日 | 休息 | — |

**冬令时（EST）会整体平移 1 小时**：美东仍是 20:00–04:00，但北京时间变成 **09:00–17:00**。
工作日（周一到周五）不变。小程序会实时算出来显示，你一眼就能核对。

> 这一点很重要，也是之前出错的地方：**窗口由北京星期决定，不受美股节假日影响**。
> 早期版本把窗口绑在「美东交易日」上，结果把上班日推成了周二~周六，现在已修正并有回归测试锁定。
>
> 想自己核验，跑 `npm run snapshot`，它会打印本周排班表和逐小时状态。

## 四、功能

### 首页

按你的要求**去掉了上班倒计时**，重新排版为：

| 区块 | 说明 |
| --- | --- |
| 页头 | 当前时间 + 「上班中 / 休息中」状态胶囊 |
| 行情环境条 | 美股时段（盘前/盘中/盘后/隔夜/休市）、美东时间、你的时段（北京 08:00-16:00），以及今天对应哪一段美东 |
| **今日 SOXL** | 自动汇总与 SOXL 相关的条目，第一条高亮 |
| **持仓** | 未平仓的 SOXL 聚合为持仓股数、均价、占用成本（无持仓时自动隐藏） |
| 今日要事 | 待办清单 |
| 今日打卡 | 10 项改成**胶囊**，一屏看完，点一下即打卡 |
| 小指标 | 连续打卡天数、本周复盘笔数、本周盈亏 |

### 复盘页（核心）

只填 **入场价 / 方向 / 股数 / 出场价**，盈亏自动算：

```
做多：(出场价 - 入场价) × 股数
做空：(入场价 - 出场价) × 股数
```

- 填了**止损价**，额外给出 **R 倍数**（这笔赚了几个风险单位）
- **出场价留空**就记成「持仓中」，之后随时补填，补填时实时预览盈亏
- 盈亏分析：胜率、净盈亏、盈亏比、单笔期望、平均盈亏、平均 R、连胜/连亏、最大单笔盈亏
- 填出场价时如果方向与价格明显矛盾（做多却填了更低的出场价），会提醒但不阻止

### 仓位计算器

输入 **进仓股数 + 入场价 + 止损价**，算出：

- **投入资金**（股数 × 入场价）
- 每股风险、**最大亏损**、风险占投入的百分比
- **1R / 2R / 3R 目标价**，以及对应盈利与收益率

例：500 股、$30 入场、$28.5 止损 → 投入 **$15,000**，最大亏损 **-$750**（风险占投入 5%），
2R 目标 $33 盈利 **+$1,500**。

> 不再需要账户资金和风险百分比——股数由你直接给，和复盘表单一致。
> 只填股数和入场价也能用，会先给出投入资金，提示你补止损价再算风险。
> 「把计划记入复盘」会把你填的股数、入场价、止损价、方向一起带过去。

### 其他

- **早报**：分 **SOXL 相关 / 美股财经 / 国内 / 其他**，内容来自 `news.json`
- **电台**：网易云歌单，填 `neteaseId` 可页面内播放，否则一键跳 App

## 五、日常维护

### 更新早报（每天 7:50 前）

编辑 `web/news.json`：

```json
{
  "updatedAt": "2026-10-17 07:50",
  "groups": [
    {
      "key": "us",
      "name": "美股财经",
      "items": [
        {
          "title": "标题（必填）",
          "body": "一两句解读（可选）",
          "source": "来源（可选）",
          "time": "07:40（可选）",
          "url": "https://原文链接（可选）",
          "soxl": true
        }
      ]
    },
    { "key": "cn", "name": "国内", "items": [] },
    { "key": "other", "name": "其他", "items": [] }
  ]
}
```

**`"soxl": true` 是关键**：加上它，这条就会同时出现在首页的「SOXL 今日关注」和早报的「SOXL 相关」专区。
标题或正文里出现 `SOXL` 也会被自动收进去，所以不加标记也不会漏。

改完保存、上传覆盖，手机刷新（或切页再切回）即可。`key` 必须是 `us` / `cn` / `other`。

### 让歌单能在页面内播放

网易云 App → 歌单 → 分享 → 复制链接，形如
`https://music.163.com/#/playlist?id=123456789`，把 `123456789` 填进 `music.json` 的 `neteaseId`。

### 换图标

改 `web/scripts/make-icons.py` 里的颜色或文字，然后 `python web/scripts/make-icons.py`。

### 改主要交易标的

小程序内「我的 → 主要交易标的」直接改（默认 SOXL），首页和早报的专区会跟着变。

## 六、数据安全

- 所有数据存在**你手机浏览器的本地存储**，不上传任何服务器。
- 「我的 → 导出备份」把全部数据复制到剪贴板，粘贴到备忘录保存；「导入备份」可还原。
- ⚠️ 清浏览器数据或换手机会丢，**建议每周导出一次**。

## 八、已知边界

- **没有实时行情**。不接任何行情源，价格手录（持仓、出场价）。免费行情源不稳定，且未备案行情有合规风险。
- **早报不能主动推送到手机**。纯静态托管没有服务端定时任务，现在是「你点开就有最新内容」+ 每 30 分钟自动重拉。
  真正的定时推送需要 Serverless Cron + Bark/Server酱，见第九节。
- **网易云内嵌播放可能被拦**。这是网易云对站外嵌入的限制，已提供「复制链接 / 网易云打开」兜底。

## 九、如果一定要每天 7:50 收到推送

三个路径，按推荐度：

1. **手机日历提醒（最简单，零成本，推荐）**
   手机日历建一个每天 7:50 的重复提醒「看早报」，点开直接进工作台。1 分钟搞定。
   你现在 8:00 上班，7:50 正好在上班前 10 分钟看到。
2. **Serverless 定时任务 + 推送**
   Cloudflare Workers / Vercel Cron 每天 7:50 抓新闻写进 `news.json`，再调 Bark / Server酱 / Telegram Bot 发推送。
   需要一点后端代码，我可以帮你搭。
3. **邮箱订阅** — 不推荐，噪音大。

## 十一、合规

个人记录工具，不含实时行情、荐股、代客交易、资金操作。
新闻栏仅为手动整理的摘要 + 原文链接，不构成任何投资建议。
